# AIP06 Agents Design System

样板页：`AIP06-current-functions.html#agents`

本轮只在现有智能体页面验证这套规则。页面继续使用 AIP06 当前数据结构与功能，包括筛选、排序、新建、详情、编辑、进入对话和更多操作。Chat 保持 AI Workspace 形态，其他管理页暂未套用。

## Layout Rules

- 产品层使用两级导航：左侧全局产品导航负责跨业务，智能体模块导航负责当前业务内的状态视图。
- 主工作区保持白色、宽阔、可滚动；桌面端模块导航固定为约 `196px`，主内容占据剩余宽度。
- 页面信息顺序固定为：Page Header → 运行概览 → 下一步行动 → 常用智能体 → 全部智能体管理。
- Section 之间使用 `28px` 左右垂直间距；Section 内标题与内容保持 `12px` 左右间距。
- 移动端收起第二级导航，概览改为 2×2，任务步骤改为 2 列，业务卡片改为单列。

## Card Rules

- Card 只承载可独立理解、可独立操作的对象；Section 本身不再套一层 Card。
- 智能体卡片一级信息为 Name、Purpose、Status。
- 二级信息为最近使用、质量/健康、最近更新。
- Model、Knowledge、Skill 等技术配置置于底部弱化行，不抢占首屏判断。
- 白底、弱边框、极轻阴影；状态通过 Badge 表达，不为每张卡片使用彩色背景。
- 常用智能体卡片提供“查看配置、进入对话、更多操作”，保持与原有功能一致。

## Table Rules

- 全量管理默认使用表格，列顺序围绕业务判断：智能体 → 用途 → 状态 → 最近使用 → 质量/健康 → 最近更新 → 操作。
- 技术配置作为用途列的辅助文本展示，避免单独占用多个高权重列。
- 首列同时提供 AI 身份、名称、版本和负责人；点击名称进入详情。
- 行内主操作保持少量且稳定，其他操作收进更多菜单。
- 搜索、状态筛选、排序和显示模式切换放在表格上方同一工具栏。

## Navigation Rules

- 全局导航只表达 AIP06 的产品功能边界，不在智能体页重复业务细节。
- 模块导航只表达智能体管理视图：概览、可用、草稿、已停用、配置异常。
- 每个状态项显示数量，并通过 URL 查询参数保留筛选状态。
- 激活态使用浅蓝底与 Brand Blue；图标、文字、数量共同提供识别，不依赖颜色单独传达状态。

## Status Rules

- 业务状态与运行质量分开：`可用/草稿/已停用/配置异常` 表示生命周期，`健康/待完善/需处理` 表示质量判断。
- 绿色只用于可用与健康，黄色用于待完善，红色用于异常。
- 已完成智能体显示配置完整度与下一步验证建议，不永久展示 Onboarding。
- 未完成智能体才显示四步配置流程：01 基础配置、02 连接知识、03 配置能力、04 测试发布。

## Interaction Rules

- 主操作使用 Brand Blue；次操作使用中性按钮或文字按钮。
- 页面首屏只保留一个最重要的创建入口，模块内操作靠近其对象。
- 筛选即时生效，并通过路由保留；空结果提供明确原因和新建入口。
- Hover 仅提高边框或轻阴影，不使用明显位移和大面积动效。
- 所有图标按钮必须有可访问名称，键盘焦点使用清晰的 Brand Blue Focus Ring。
- 原有详情、编辑、对话、筛选、排序、列表/卡片切换继续可用；视觉升级不改变数据模型和操作语义。

## 延展边界

- Knowledge、Evaluation、Skills、MCP、Settings 后续应复用以上 Token、导航、状态、表格和交互规则，并按各页面的信息任务重新编排内容。
- Chat 不套用管理后台的 Section/Card 结构，继续以会话、回答、来源与输入区组成 AI Workspace。
